# שקיפות כספית לוועד הבית — גרסת אתר סטטי

עמוד HTML/CSS/JS יחיד (`index.html`), ללא build step, מוכן לפריסה ב-Vercel כאתר סטטי.

## פריסה ב-Vercel

1. היכנסו ל-[vercel.com](https://vercel.com) והתחברו.
2. New Project → Import מהריפו `agenticflow-project`.
3. **Root Directory:** הגדירו ל-`vaad-finance-site` (חשוב — זה לא שורש הריפו).
4. אין Build Command ואין Output Directory — Framework Preset: **Other**. Deploy.

Vercel ייתן קישור ציבורי מיידית, ויעדכן אותו אוטומטית בכל push לענף הזה.

## מגבלה נוכחית — אין שיתוף נתונים חי

הגרסה הזו זהה בפונקציונליות לגרסת ה-[Claude Artifact](https://claude.ai/code/artifact/7f4ddc1f-f0b6-4e13-be3e-6318cf4b034f)
(אותו קוד בדיוק — כניסת ועד/אדמין עם סיסמה, ניהול קטגוריות ודירות מלא), **חוץ** מהשיתוף
החי בין צופים: ב-Claude Artifact עדכון של ועד/אדמין מתפרסם אוטומטית לכל מי שפתוח בדף.
כאן, כשאין `window.claude` (בכל אתר שאינו artifact של Claude), כל עדכון נשמר רק בדפדפן
המקומי של מי שערך — דייר אחר שיפתח את הקישור לא יראה את השינוי. הדף עצמו מציג את זה
בבירור ("מצב תצוגה מקומי" בפינה העליונה).

**השלב הבא:** לחבר Supabase (כמתואר באיפיון) כדי שגם כאן יהיה שיתוף נתונים אמיתי בין
כל הדיירים, ללא תלות ב-Claude.
